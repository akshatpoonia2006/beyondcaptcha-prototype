Existing HTML Form + BeyondCAPTCHA Widget

Below is a standard HTML web form protected by the BeyondCAPTCHA client SDK. The widget attaches seamlessly with passive verification for standard users and accessible mode when requested.

DEMO ONLY: Enter any credentials
[ View Integration Code ]

3-step integration into any existing web form: 

<!-- 1. Include Widget CSS & JS -->
<link rel="stylesheet" href="/static/css/beyondcaptcha-widget.css">
<script src="/static/js/beyondcaptcha-widget.js"></script>

<!-- 2. Mount Container in Existing Form -->
<form id="myForm" action="/submit" method="POST">
  <input type="text" name="username" />
  <input type="password" name="password" />
  
  <!-- BeyondCAPTCHA widget container -->
  <div id="beyondcaptcha-widget-mount"></div>

  <button type="submit">Submit</button>
</form>

<!-- 3. Mount BeyondCAPTCHA SDK -->
<script>
  BeyondCaptcha.mount('#myForm', {
    apiUrl: '/api/verify'
  });
</script>
